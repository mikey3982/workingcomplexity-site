# Working Complexity — Project Instructions

**Before producing any output for this project, read `BRAND.md` in full.**

This is a Working Complexity project. Every artefact — document, deck, PDF, report, diagram, web copy, email, or code output intended for a client — must conform to the Working Complexity brand system defined in `BRAND.md`.

## Mandatory before starting any WC artefact

1. Read `BRAND.md` completely.
2. Identify which sections apply to the artefact type (see the lookup table in §1 of BRAND.md).
3. Apply the brand. Do not simplify it to meet a deadline.

## Hard constraints (never override without explicit instruction from Mike)

- **Dark-first.** Blueprint Navy `#060D1B` as the default background. Light variant only for print-economy documents.
- **Hex grid.** Pointy-top hexagonal grid on all covers and section dividers at specified opacity. Never on body content slides.
- **Logo mark.** Three nested pointy-top hexagons (Blueprint Blue / Brass Gold / Blueprint Blue) with centre dot — the primary visual symbol. Never recoloured, rotated, or filled solid. File: `logo.svg`.
- **Typefaces.** Inter + Space Mono only. No substitutions.
- **Gold is scarce.** One word in a headline, one element in a diagram, one CTA. Never large fills.
- **No stock healthcare imagery.** No stethoscopes, pill bottles, smiling clinicians, or doctors pointing at tablets.
- **UK English throughout.** Organisation, centre, behaviour, programme, analyse.
- **Voice.** First person plural. Sentence case. Em dashes. Short paired statements. Never "simply", "leverage", "unlock", "stakeholders".
