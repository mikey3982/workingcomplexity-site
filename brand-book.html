workingcomplexity.health
WC-BRAND  /  §3 VOICE  /  REV.B
Voice principles
  • Hold complexity. Never reach for "simply" or "just". If it's hard, say so.
  • Short, paired statements. "Not simplified. Understood." "Emergent by design. Rigorous by necessity."
  • Concrete over abstract. Name the clinician, the ward, the handoff. Avoid "stakeholders".
  • UK English. Organisation, centre, behaviour, programme, analyse.
  • Em dashes, used well. Hold two ideas in relation — not as a pause.
  • First person plural. "We" not "the team" or "WC".
Worked examples
AVOID

"We leverage cutting-edge systems thinking to unlock transformational outcomes for healthcare stakeholders."

PREFER

"We map the full assemblage of a situation — its actors, its tensions, its hidden structures — before we propose anything."

Stack & structure

  • Plain HTML / CSS / JS — no framework, no build step
  • Hosted on Netlify, deployed from GitHub main branch
  • Contact form: Netlify Forms, notification to hello@workingcomplexity.health
  • Fonts: Inter + Space Mono via Google Fonts CDN

Visual spec

  • Background: Blueprint Navy #060D1B (dark-first; no light variant)
  • Hex grid: pointy-top, rgba(74,144,226,0.05), CSS SVG pattern 69.28×120px
  • Logo mark (§4.2) in hero at 65% opacity, nav favicon, footer 48px
  • Services: hex honeycomb cards, clip-path polygon, 300×346px
